1. **Controlled vocabulary:** one agreed name for each thing.
2. **Taxonomy:** those names arranged in a hierarchy.
3. **Thesaurus ([SKOS](term:skos)):** adds synonyms, languages and related terms.
4. **Ontology ([OWL](term:owl)):** classes and logic a reasoner can infer from.
5. **Rules ([SHACL](term:shacl)):** check that data meets its constraints.

The standards are RDF, written as [Turtle](term:turtle), JSON-LD or RDF/XML.

**Start light:** most search needs SKOS, not OWL.
